# 🛒 E-commerce Sales Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analysing e-commerce sales data using Microsoft Excel to identify sales trends, evaluate product performance, compare store performance, and generate meaningful business insights.

As an aspiring Data Analyst, I completed this project to develop my practical skills in data cleaning, Excel formulas, data summarisation, descriptive statistics, and dashboard creation.

The project demonstrates how raw sales data can be transformed into useful information to support data-driven business decisions.

## 🎯 Project Objectives

- Organise and structure raw data using Excel tables.
- Clean the dataset by identifying duplicates, missing values, inconsistent data, and formatting issues.
- Apply Excel formulas and functions to perform calculations and logical operations.
- Use XLOOKUP and VLOOKUP to retrieve information and combine related tables.
- Create PivotTables to summarise sales data from different perspectives.
- Calculate descriptive statistics to understand the dataset.
- Build charts and an interactive dashboard to communicate key findings.
- Prepare a one-page business summary with insights and recommendations.

## 📂 Dataset Information

**Dataset:** E-commerce Sales Dataset

**Source:** [E-commerce Store Dataset — GitHub](https://github.com/GeethaGunasekaran1/Dataset_rep/raw/refs/heads/main/Ecommerce_Sales_Dataset_updated.xlsx)

The main tables used in the project are:

- `Sales_Fact` — sales transactions and order details
- `Customer_Dim` — customer information
- `Product_Dim` — product details, categories, brands, and costs
- `Store_Dim` — store details and location information

## 🧹 Data Cleaning and Preparation

The data preparation stage focused on improving data quality and making the dataset suitable for analysis.

- Checked the dataset for duplicate records.
- Identified missing values in relevant columns.
- Reviewed inconsistent product IDs and lookup mismatches.
- Checked column formats and data types.
- Reviewed columns for irrelevant information.
- Used lookup functions to retrieve related product, customer, and store information.
- Organised the data into structured Excel tables.

## ❓ Business Questions

The dashboard was designed to help answer the following business questions.

### 1. Overall Sales Performance
- What is the total sales revenue and quantity sold?
- How do sales change over time?
- Which period recorded the highest and lowest sales?

### 2. Product Performance
- Which product generates the highest sales revenue?
- Which product category performs best?
- How do sales compare across categories?

### 3. Store Performance
- Which store generates the highest revenue?
- Which store has the lowest sales?
- How does performance vary across stores and regions?

### 4. Payment Method Analysis
- Which payment method is used most frequently?
- Which payment method contributes the highest revenue?
- How do sales compare across payment methods?

### 5. Sales Trend Analysis
- Which month recorded the highest and lowest sales?
- Are there recurring monthly sales patterns?
- How do sales trends support future planning?

## 💡 Key Findings

The initial analysis of the workbook indicated the following:

- Sports was the highest-revenue category among records successfully matched to the product table.
- PayPal recorded the highest sales value among the payment methods.
- STORE8 was the highest-revenue store in the analysed data.
- PROD39 was the top product by recorded sales value.
- March 2025 was the strongest month by recorded sales value.

These findings are based on the available workbook data. Product-category results should be reviewed after resolving unmatched product IDs.

## 📌 Business Recommendations

- Review stock availability for high-performing products and categories.
- Compare store performance to identify practices that may be useful elsewhere.
- Evaluate payment methods using transaction costs and customer convenience.
- Investigate monthly sales patterns before planning promotions.
- Validate missing and unmatched records before finalising reports.
- Compare revenue with product costs and discounts before drawing conclusions about profitability.
